# Aquarius Web App

This is the user-facing interface of Aquarius.

Built with:
- Next.js App Router
- TypeScript
- TailwindCSS

## Purpose
Define **user journeys and layout composition**, not business logic.

## Responsibilities
- Routing and layout boundaries
- Visual hierarchy and UX
- Rendering protocol intelligence

## Must NOT do
- Fetch raw blockchain data
- Implement protocol logic
- Hold protocol state globally

## Key Concept
Routing defines reality.
Once inside a protocol route, nothing leaks.
