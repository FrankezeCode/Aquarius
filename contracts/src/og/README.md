# 0G Chain — `RiskCommitmentAnchor`

Minimal EVM contract deployed on **0G Chain** (EVM) — **mainnet** chain id `16661` or **Galileo testnet** chain id `16602` — to anchor deterministic `bytes32` commitments from Aquarius (e.g. output of `POST /api/v1/zg/pipeline`). Network is chosen via `OGF_NETWORK` when running the deploy script.

See **[docs/integrations/0g-chain-hackquest-proof.md](../../docs/integrations/0g-chain-hackquest-proof.md)** for deploy instructions, HackQuest submission checklist, and security notes.
